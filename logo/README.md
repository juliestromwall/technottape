# Logo

`explore.html` holds six directions, rendered to `preview-directions.png`.
Each direction is shown four ways: mark alone, horizontal lockup, reversed on
charcoal, and at real 24px / 32px favicon size.

| Direction | Idea | Read |
|---|---|---|
| A — The Stack | Three aligned bars; the current placeholder mark refined | Clean, but reads as a hamburger menu icon at small size |
| B — `tnt.` | Lowercase monogram with a full stop, sibling to the `js.` mark on the business card | Strongest small-size performance; distinctive |
| C — Not | Pure type, "NOT" in terracotta. No symbol | Best wordmark; the stacked favicon is the weak part |
| D — The Joint | Two interlocked dovetail blocks | Muddy at this size — the joint does not read |
| E — Patched, then Solid | Broken dashed line above one solid bar | Concept is right, but currently reads as loading dots |
| F — The Fastener | Hex head — what you use when tape will not do | Warm and distinctive; holds up small |

**Not yet chosen.** Once a direction is picked, the final assets are:
`mark.svg`, `lockup.svg`, `lockup-reversed.svg`, and `app/icon.svg` in the site.

Note: the SVGs in `explore.html` use live `<text>` set in Inter. Final wordmark
assets should have the type converted to outlines so they do not depend on the
font being installed.

## Round two

`explore-2.html` → `preview-directions-2.png`. Six new directions, generated by
`build.py` — the mark geometry lives once in that script, which writes both the
comparison sheet and the standalone SVGs, so the two can't drift apart.

Round two adds a **16px** favicon test (real browser-tab size) because that is
where marks actually fail.

| Direction | Idea | Read |
|---|---|---|
| G — The Beam | Structural column: top plate, web, base plate | Reads more as a capital "I" than a T; the web thins out at 16px |
| H — No Tape | A tape roll with a stroke through it | Decodes instantly, but currently drab and a bit "no entry" |
| I — North Star | Minneapolis, the North Star State, the thing you steer by | Elegant and survives 16px; says nothing about tape |
| J — The Seam | Two blocks locked with a stepped seam | The joint reads now, unlike round one's dovetail |
| K — Unbroken | One continuous stroke that never lifts | Reads as a "2" or a "Z" — the concept doesn't land |
| L — The Level | Spirit level, bubble dead centre | Reads as a UI toggle switch, not a tool |

## Round three — built from the site's own rule

`build3.py` → `explore-3.html` → `preview-round3.png`, with SVGs in `svg3/`.

The first two rounds failed because they were abstract symbols invented from
nothing. This round takes the rule the site already uses and that Julie
responded to: **substance is solid, tape is hollow.** The word "tape" is
stroke-only in the hero, in the "with tape." heading, and in the footer.

| Direction | Idea |
|---|---|
| A — Stacked Wordmark | TECH / NOT / TAPE in three tight lines, TAPE hollow |
| B — Inline Wordmark | The same, horizontal, for the header and signatures |
| C — TNT | Initials with the final T hollow |
| D — The Strip | Solid block with a hollow strip laid across it |
| E — Two Solid, One Hollow | The existing bar mark with the short bar outlined |
| F — Hollow T | Hollow crossbar, solid stem |

**Known constraint:** a stroke-only mark thins toward nothing below about
24px. Whichever wordmark is chosen should be paired with a solid compact mark
(C, E or F) for favicons and app icons. That is a normal two-part identity,
not a compromise.

Fixed in this round: B and C positioned "TAPE"/"T" with a hand-computed x
offset, which overlapped the preceding letters. They now use a single `<text>`
with a `<tspan>`, so the text engine advances the pen and the glyphs cannot
collide.
